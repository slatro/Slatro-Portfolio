# Slatro Portfolio | Premium Developer Hub & Web3 Showcase

A highly performant, single-page developer showcase designed completely from scratch. This custom portfolio features an elegant glassmorphism dashboard layout, dynamic animating background light glows, a sleek developer grid overlay, and fully polished micro-interactions.

---

## 🎨 Features & Visual Highlights

1. **Dashboard-Style Split Layout:**
   - **Sticky Left Sidebar:** A clean, fixed desktop profile sidebar featuring a customizable avatar, title, biography, social links, and live online indicators.
   - **Compact Mobile Banner:** Automatically responsive top banner layout for smaller screens, bringing projects above-the-fold immediately.

2. **State-of-the-Art Aesthetics:**
   - **Interactive Developer Grid Overlay:** Subtle grid lines and multiple radial glows (emerald green and indigo blue) giving it a high-end SaaS feel.
   - **Enhanced Frosted Glassmorphism:** Cards styled with heavy backdrop-blur, custom saturation, and a real polished glass top reflection highlight (`inset` box-shadows).
   - **Rotating Cyberpunk Avatar:** Animated rotating glowing neon border wrapping the profile picture.

3. **Web3 & Game Ecosystem:**
   - Built to demonstrate production-ready applications with beautiful category tag filters and keyword search matching.

## 💾 Customizing the Portfolio Data

All project data, profile details, and links are dynamically loaded from a single unified state. To customize this portfolio permanently for your own details:

1. Open `index.html` in your favorite code editor (VS Code, Cursor, etc.).
2. Locate the `const INITIAL_DATA = { ... };` constant declaration near the top of the `<script>` tag.
3. Modify the profile metadata, bio descriptions, social URLs, or project details to match your background.
4. Save the file and you are ready to deploy!

## ☁️ Zero-Cost Deployment

This application is composed of a completely unified setup, making hosting completely free and straightforward:

### Option A: Vercel (Recommended)
1. Sign up/log in to your [Vercel](https://vercel.com) account.
2. Link your GitHub repository or upload the directory directly using the Vercel CLI.
3. Your premium showroom will be live globally in seconds.

### Option B: GitHub Pages
1. Create a new repository on GitHub named `slatro-portfolio`.
2. Push your `index.html`, `profile.jpg`, and `README.md` to the `main` branch.
3. Navigate to **Settings > Pages** on your repo, choose the `main` branch as the build source, and click Save.
4. Your site will be hosted publicly at `https://<your-username>.github.io/slatro-portfolio/`.
